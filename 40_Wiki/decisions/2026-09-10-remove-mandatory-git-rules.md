# Отмена обязательных Git/GitHub-правил

Date: `2026-09-10`
Status: `accepted`

## Контекст

Пользователь заметил, что проценты использования Codex быстро расходуются из-за частых инструментальных действий: чтения файлов, проверок, коммитов, пушей и верификации после каждого небольшого запроса.

Ранее действовало правило использовать GitHub как обязательный источник правды и делать автоматический коммит после каждого завершённого запроса, если появились знания, инструкции, файлы или логи.

## Решение

Обязательные правила, связанные с Git, GitHub, автоматическими коммитами и обязательным чтением репозитория перед каждым запросом, отменены.

База знаний остаётся полезным рабочим справочником, но используется по необходимости:

- когда пользователь явно просит сохранить или прочитать знания;
- когда задача продолжает предыдущую тему из базы;
- когда без сохранённых файлов невозможно корректно продолжить работу.

Коммиты, push/pull и проверки удалённого состояния не выполняются автоматически после каждого обычного вопроса. Их нужно делать только по явной просьбе пользователя или когда задача прямо связана с изменением файлов и синхронизацией.

## Последствия

- Простые вопросы отвечаются без чтения репозитория и без коммита.
- Журналы и решения создаются только для действительно повторно используемого контекста.
- Исторические записи о прежнем GitHub source-of-truth правиле остаются в базе, но не являются действующими инструкциями.
