# GitHub как единый источник правды

Date: `2026-09-09`
Status: `accepted`

## Контекст

Пользователь работает с несколькими устройствами и AI-чатами. Локальный контекст отдельных чатов и ПК не должен быть единственным местом хранения инструкций, заметок, решений и журналов работы.

## Решение

Репозиторий `Andrew1909/knowledge-base` используется как единый источник правды для базы знаний, проектов, решений, заметок, журналов работы, пользовательских инструкций и AI-навыков.

AI-агенты должны начинать работу с актуального состояния этого репозитория, читать `README.md`, `AGENTS.md`, релевантные `_index.md`, а для проектов — проектный `README.md` и `log.md`.

После каждого завершённого пользовательского запроса, если появились новые знания, инструкции, файлы или логи, изменения нужно коммитить автоматически.

## Причины

- Контекст должен переживать отдельные чаты и устройства.
- GitHub даёт историю изменений, откат и синхронизацию.
- `AGENTS.md` позволяет новым AI-сессиям получать рабочие правила из репозитория.
- Логи и решения уменьшают необходимость пересказывать одно и то же в каждом новом чате.

## Ограничения

- Секреты, токены, приватные ключи, cookie, seed-фразы и другие чувствительные данные не записываются в репозиторий.
- Сырые полные диалоги сохраняются только по явному запросу пользователя и после проверки, что там нет секретов или закрытых данных.
- Локальные случайные файлы конкретного ПК не добавляются автоматически.
- Автоматические коммиты возможны только там, где у AI-агента есть доступ к GitHub или локальному git-репозиторию.

## Последствия

- Новые постоянные инструкции записываются в `AGENTS.md`, `40_Wiki/processes/` или `40_Wiki/decisions/`.
- Итоги диалогов и сессий записываются в `50_Logs/`.
- Новые материалы без понятного места сначала попадают в `00_Inbox/`.
- Важные решения оформляются отдельными Wiki-записями.

## Проверка

Новый чат должен суметь ответить, что `Andrew1909/knowledge-base` — источник правды, прочитав `README.md` и `AGENTS.md`.
