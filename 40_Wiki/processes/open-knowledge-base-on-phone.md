# Как открыть базу знаний на телефоне

## Когда использовать

Когда нужно продолжить работу с другого устройства через GitHub-репозиторий `Andrew1909/knowledge-base`.

## Через приложение GitHub или браузер

1. Открыть приложение GitHub или сайт `github.com`.
2. Войти в аккаунт, у которого есть доступ к `Andrew1909/knowledge-base`.
3. Открыть репозиторий `Andrew1909/knowledge-base`.
4. Начать с `README.md`.
5. Затем открыть `AGENTS.md`.
6. Для продолжения старого диалога открыть `50_Logs/dialogs/2026-09-09-codex-dialog-index.md`.
7. Выбрать нужную тему и скопировать название файла/раздела в новый запрос AI.

## Через ChatGPT на телефоне

1. Открыть ChatGPT на телефоне.
2. Проверить, что GitHub connector подключён к аккаунту и имеет доступ к репозиторию `Andrew1909/knowledge-base`.
3. В новом чате написать:

```text
Прочитай репозиторий Andrew1909/knowledge-base. Начни с README.md и AGENTS.md.
Потом открой 50_Logs/dialogs/2026-09-09-codex-dialog-index.md и помоги продолжить нужную тему.
```

4. Если ChatGPT не видит репозиторий, повторно выдать доступ GitHub connector к приватному репозиторию.

## Что проверять

- Успех: AI видит `README.md`, `AGENTS.md` и может ссылаться на файлы из `50_Logs/dialogs/`.
- Ошибка: AI говорит, что репозиторий не найден или возвращает `404`; значит connector не имеет доступа к приватному репозиторию.
- Ошибка: AI отвечает только из памяти чата и не читает файлы; нужно прямо попросить прочитать `README.md`, `AGENTS.md` и нужный `_index.md`.

## Важное правило

GitHub переносит файлы, знания и журналы, но не гарантирует перенос полного состояния старого чата. Поэтому каждую важную тему нужно фиксировать в файлах репозитория и коммитить после завершения запроса.
