# 10_Projects

Активные проекты: задачи с конкретным результатом, границами и состоянием.

## Когда использовать

Создавать папку проекта, когда есть цель, которую можно завершить или явно поставить на паузу.

## Рекомендуемая структура проекта

```text
10_Projects/project-name/
├─ README.md
├─ log.md
└─ notes/
```

## Правила

- В `README.md` проекта держать цель, контекст, текущее состояние и ссылки.
- В `log.md` проекта писать краткую хронику изменений и решений по проекту.
- Долгоживущие знания выносить в `40_Wiki/` и ссылаться на них.
- Новые проекты можно начинать из `80_Templates/project.md`.
