# 50_Logs

Хронология работы: что произошло, когда, в каком контексте и куда смотреть дальше.

## Разделы

| Раздел | Назначение |
|---|---|
| `daily/` | Короткие итоги по дням. |
| `sessions/` | Журналы отдельных AI/рабочих сессий. |

## Правила

- Писать кратко: дата, контекст, сделано, ссылки, следующий шаг.
- Важные решения оформлять в `40_Wiki/decisions/` и ссылаться на них.
- Лог не заменяет проектный README и не должен становиться свалкой фактов.
