# 50_Logs/daily

Короткие дневные записи: что было сделано и какие следы оставлены в базе.

## Именование

Рекомендуемый формат файла: `YYYY-MM-DD.md`.

## Минимальный формат записи

```markdown
# YYYY-MM-DD

## Сделано

- ...

## Важные ссылки

- ...

## Следующий шаг

- ...
```

## Правила

- Не писать длинный пересказ сессии, если есть отдельный session log.
- Ссылаться на проекты, решения и Wiki-записи.
