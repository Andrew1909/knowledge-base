# Knowledge Base

Единый источник правды для базы знаний, проектов, решений, заметок и журналов работы.

Этот репозиторий используется между устройствами и AI-чатами. Если информация важна для повторного использования, она должна жить здесь, а не только в переписке.

## Как начинать работу

1. Прочитать этот `README.md`.
2. Определить раздел по задаче и прочитать соответствующий `_index.md`.
3. Для проектной задачи прочитать `10_Projects/<project>/README.md` и `10_Projects/<project>/log.md`, если они есть.
4. Новые неразобранные материалы класть в `00_Inbox/`.
5. Важные итоги, решения и ход работы фиксировать в `50_Logs/`.

## Архитектура

| Раздел | Назначение |
|---|---|
| `00_Inbox/` | Входящие заметки, идеи, ссылки и материалы без окончательного места. |
| `10_Projects/` | Активные проекты с конкретным результатом и сроком. |
| `20_Areas/` | Постоянные зоны ответственности и долгоживущие направления. |
| `30_Resources/` | Справочные материалы, источники и подборки по темам. |
| `40_Wiki/` | Устойчивые знания для LLM и человека: понятия, люди, компании, продукты, процессы, решения. |
| `50_Logs/` | Хронология работы: daily-заметки и журналы сессий. |
| `80_Templates/` | Шаблоны для новых проектов, заметок, решений, встреч и промптов. |
| `90_Archive/` | Завершённые или устаревшие материалы, сохранённые ради истории. |

## Правила хранения

- Не создавать loose files в корне репозитория. Корень нужен только для главных входных файлов и служебной конфигурации.
- Не хранить секреты, токены, пароли, приватные ключи и учетные данные.
- Не придумывать факты: если данных не хватает, писать `TODO: уточнить`.
- Стабильное знание хранить один раз и ссылаться на него из журналов и проектов.
- Хронику писать в `50_Logs/`, а не смешивать с устойчивыми правилами.

## Быстрый маршрут

- Есть новая мысль или файл без места: `00_Inbox/`.
- Есть цель с результатом: `10_Projects/`.
- Есть постоянная область жизни или работы: `20_Areas/`.
- Есть справочник или внешний материал: `30_Resources/`.
- Есть знание, которое должен помнить любой AI: `40_Wiki/`.
- Есть итог дня или сессии: `50_Logs/`.
